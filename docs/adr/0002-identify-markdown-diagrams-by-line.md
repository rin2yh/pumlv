# ADR 0002: Markdown内の図をファイルパスと開始行番号で識別する

## Context（背景）

PR #231 では、Markdown内の複数のPlantUMLコードブロックを個別に選択・プレビューするため、各図を識別する必要がある。ファイルの編集により、ブロックの内容や位置は変化する。

## Decision（決定）

各図の識別には、ファイルパスと開始フェンスの行番号（1始まり）の組み合わせを使用する。永続IDの管理や編集前後の差分追跡を導入せず、実装の単純さを優先する。代替案である内容ハッシュや永続IDによる識別は、現時点では採用しない。

## Consequences（影響）

先行するブロックの編集などで開始行番号が変わると、選択状態が維持されない場合がある。また、同じ行番号に別の図が移動した場合は、その図が選択される可能性がある。選択中の識別子が存在しなくなった場合は、同じファイルの先頭の図を選択する。編集をまたいだ図の同一性を保証しないというトレードオフを受け入れる。
